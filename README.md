# quant. prototype v5

Static quant interview practice prototype with three paths:

- Quant Trader
- Quant Researcher
- Quant Developer

The imported problem bank contains 386 questions and is split across `questions/bank-*.js` so the browser can load the static bank without per-question generation. Practice decks can be shuffled by role, category, and matched subtopic. Questions do not repeat until the current shuffled deck is exhausted.
